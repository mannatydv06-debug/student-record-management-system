

Student Record Management System

A beginner-friendly Python project developed as part of my CodeNova Python Programming Internship.

About the Project

The Student Record Management System is a menu-driven application that helps users manage student information through a simple command-line interface.

Features

- Add new student records
- View all student records
- Search for a student using their ID
- Update existing student information
- Delete student records with confirmation
- Save records in a JSON file
- Validate student details and marks

Technologies Used

- Python 3
- JSON for data storage
- VS Code / Python Code Pad

Student Information Stored

Each record contains:

- Student ID
- Name
- Age
- Course
- Marks

How to Run

1. Install Python 3.

2. Download or clone this repository.

3. Open a terminal in the project folder.

4. Run:
   
   "python main.py"
   
   On some systems, use "python3 main.py".

Data Storage

Student records are stored in "students.json", which is created when the program saves records. Keep this file in the same working directory when running the program.

Learning Outcomes

This project helps practise Python functions, dictionaries, loops, conditional statements, exception handling, file handling, and JSON operations.
